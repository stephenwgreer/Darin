⚙ Settings (gear icon — top right)
Opens a dialog with storage location (Browse button → native folder picker) and other future settings. Small, unobtrusive icon that doesn't clutter the header.
🕐 History button — top right
Opens a dialog listing past meetings. Each row shows date/time + Claude-generated title. Click a meeting to view its timestamped transcript and ask questions about it.
✏ Prompt Editor — accessible from bucket headers
Click the pencil/edit icon on any bucket header to open the prompt editor dialog. View, edit, delete any built-in prompt. Create new prompts that land in the Custom bucket.
Custom bucket — bottom of left column
User-created prompts appear here. "+ Add Prompt" shortcut at the bottom opens the prompt editor. Custom prompts work identically to built-in ones during meetings.
