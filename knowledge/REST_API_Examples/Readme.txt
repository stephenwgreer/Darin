This ZIP file contains example files for the SAS Decision Management REST APIs described in
SAS Intelligent Decisioning: SAS Decision Management REST API Examples and 
SAS Intelligent Decisioning: Using Custom Node Types. These documents are 
available at
https://go.documentation.sas.com/doc/en/edmcdc/default/edmug/titlepage.htm
(Select "REST API Examples" in the left navigation pane.)


These examples were developed using Python 3.7 in Jupyter Notebook, which 
was launched from Anaconda Navigator.

To extract these files to your computer:

1. Save the zip file into a folder on your machine.

2. In Windows Explorer, right-click 'REST_API_Examples.zip', and select 'WinZip' 
   and 'Extract to here'. Windows creates a folder named REST_API_examples 
   that contains the example files.


The code in the file 'methods_and_access_token.py' must be prepended to each of the other
examples. Replace the client ID, host URL, username, and password with values
appropriate for your environment.
